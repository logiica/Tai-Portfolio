# Modern Portfolio

A modern, responsive personal portfolio website built with React, TypeScript, and Tailwind CSS. This project showcases a developer's work with immersive animations, interactive sections, and a sleek design.

## 🚀 Features

- **Immersive UI**: Parallax effects, glassmorphism, and 3D-like animations
- **Hero Section**: Typewriter effect with glowing avatar animation
- **Project Gallery**: Dynamic filtering and animated previews
- **Certificate Gallery**: Zoom-in modals for achievements
- **Responsive Design**: Optimized for desktop, tablet, and mobile
- **Theme Toggle**: Dark/Light mode with persistence
- **Smooth Interactions**: Cursor effects, micro-interactions, and lazy loading
- **Performance Optimized**: Fast loading with modern web technologies

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, GSAP, Lottie
- **3D Graphics**: Three.js, React Three Fiber
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Deployment**: Netlify

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/logiica/Tai-Portfolio.git
   cd Tai-Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🚀 Usage

- **Development**: `npm run dev` - Starts the development server
- **Build**: `npm run build` - Builds the project for production
- **Preview**: `npm run preview` - Previews the production build locally
- **Lint**: `npm run lint` - Runs ESLint for code quality
